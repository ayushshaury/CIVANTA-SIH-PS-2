# GIS + RISK-AWARE ROUTING

This module handles **GIS-based road network routing** for the NER Logistics Accessibility platform.

It uses **OpenStreetMap road network data** together with the ML team's generated `road_risk_scores.csv` to calculate and compare:

* Standard shortest route
* Risk-aware route

The risk-aware route assigns higher routing costs to roads with higher predicted risk or disruption.

## Folder Structure

```text
routing/
├── app.py                         # Streamlit GIS + routing application
├── road_risk_scores.csv           # Risk database generated by ML team
└── README.md                      # Routing module documentation
```

## What This Module Does

The routing application:

1. Takes start and destination latitude/longitude as input.
2. Downloads the required driving road network from OpenStreetMap using OSMnx.
3. Finds the nearest road-network nodes for the origin and destination.
4. Matches OSM road/way IDs with the ML team's `road_risk_scores.csv`.
5. Adds risk score and predicted disruption information to the road network.
6. Calculates a **standard shortest route** based on road distance.
7. Calculates a **risk-aware route** using distance + risk/disruption penalties.
8. Calculates route statistics such as:

   * Total distance
   * Average risk
   * Number of disrupted roads
9. Displays a comparison between the standard and risk-aware routes.
10. Visualizes both routes on an interactive GIS map using Folium.

## Risk-Aware Routing Logic

Each road receives a routing cost based on:

* Road length
* `risk_score`
* `predicted_disruption`

Higher-risk and disrupted roads therefore receive a higher routing cost, allowing the system to select a safer alternative when one is available.

The **Risk Weight** and **Disruption Penalty** can be adjusted from the Streamlit interface.

## Data Integration

The routing module uses the risk database generated by the ML/risk-engine team:

```text
road_risk_scores.csv
```

Expected columns:

```text
road_id
risk_score
predicted_disruption
```

The `road_id` is matched with the corresponding OpenStreetMap `way/{id}` so that the ML-generated risk information can be associated with actual road segments in the GIS network.

## How to Run

Install the required dependencies:

```bash
pip install streamlit pandas numpy networkx osmnx folium streamlit-folium geopandas
```

Then run:

```bash
python -m streamlit run app.py
```

The application will open in the browser.
